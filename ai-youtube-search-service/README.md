# 🎬 AI 유튜브 검색기 (AI YouTube Searcher)

Gemini 3.5 Transcribe 및 Gemini 3.8 Flash를 활용한 **대화형 유튜브 영상 검색 및 탐색 웹 서비스**입니다.

---

## ✨ 핵심 기능

1. **유튜브 테마 UI 레이아웃**
   - 상단 중앙 링크 검색창에서 유튜브 주소를 입력하면 즉시 영상 임베드 및 동기화
   - 사용자 요구사항에 따라 상단 오른쪽 마이크, 만들기, 알림 버튼은 제외하여 깔끔한 인터페이스 제공

2. **영상 출력 음향 크기(볼륨) 조절**
   - 플레이어 하단 전용 볼륨 슬라이더 (0~100%) 및 원클릭 음소거 토글 제공

3. **Gemini 3.5 Transcribe 오디오 전사 & 타임스탬프 추출**
   - `yt-dlp`를 통해 영상의 오디오를 고속 추출
   - `gemini-3.5-transcribe` 모델로 모든 발화 구간의 정밀 타임스탬프(`[MM:SS]`)와 텍스트를 실시간 스트리밍으로 추출

4. **영상 특정 내용 검색 & 재생 위치 이동(Seek)**
   - 우측 사이드바의 **"영상 내용 검색"**에 키워드를 입력하면 일치하는 타임라인이 실시간 필터링/하이라이트
   - 해당 타임스탬프를 클릭하면 영상 플레이어가 해당 위치(`seekTo`)로 즉시 점프하여 자동 재생

5. **Gemini 3.8 Flash 영상 Q&A**
   - 추출된 전체 타임스탬프 트랜스크립트를 컨텍스트로 주입하여 영상 내용에 관한 질문에 정확하게 답변
   - 답변 내에 인용된 `[MM:SS]` 타임스탬프를 클릭하면 해당 영상 시점으로 즉시 이동

---

## 🚀 실행 방법

### 1. 환경 변수 설정
루트 디렉토리 또는 현재 디렉토리에 `.env` 파일이 있는지 확인합니다:
```env
GEMINI_API_KEY=your_gemini_api_key_here
```

### 2. 패키지 설치
```bash
pip install -r requirements.txt
```

### 3. 서버 실행
```bash
uvicorn app:app --port 8000 --reload
```
브라우저에서 `http://localhost:8000`으로 접속하여 사용합니다.
